# 🤬 ThreatenGL

[English](#english) | [Português](#portugues)

<a id="english"></a>

Welcome to ThreatenGL!

**This fork targets Minecraft 26.3 with Fabric only. It does not support Forge, NeoForge, Quilt, or other Minecraft versions.**

ThreatenGL is a Minecraft mod that takes a stand against the outdated OpenGL version 3.2, ***threatening*** Minecraft to use the more modern version 4.6. This mod aims to explore the effects of this change.

> Minecraft: "please... anything but that!" 😰
>
> ThreatenGL: "opengl version 4.6, or else!" 😡🔪

[![ThreatenGL Banner](https://raw.githubusercontent.com/Richy-Z/ThreatenGL/main/0-OtherFiles/Logo/Banner.png)](https://modrinth.com/mod/threatengl)

## 🤨 What's the deal?

ThreatenGL is about testing the effects of changing the OpenGL version, and potentially enhancing your experience. By ***threatening*** Minecraft to switch to OpenGL 4.6, this mod aims to investigate how OpenGL version changes affect the functioning of your GPU. Users have reported smoother gameplay and better frame rates, especially on newer devices.

For a more detailed description of what this does, please visit the [GitHub repository](https://github.com/Richy-Z/ThreatenGL). (Mod developers, please read this to understand the mod in-depth!)

## ⚙️ How does it work?

ThreatenGL works its magic by tinkering with Minecraft's internals. By injecting some code into the game's graphics setup process, it convinces Minecraft to opt for OpenGL 4.6 instead of the old 3.2. This simple tweak has the *potential* to make a difference in how the game performs, as some GPU manufacturers like to use different, specific profiles for different OpenGL versions in their drivers. (I have no idea why they do that, but I'm guessing its for compatibility)

## 📥 Installing the Mod

The intended setup for this fork is Minecraft 26.3, Fabric Loader 0.20.1 or newer, and Java 25. Download the JAR from GitHub Releases or build it from the included profile, then put it in the instance's `mods` directory.

**For original upstream versions, ThreatenGL has not required additional libraries since 1.3.2-beta.1.**

## 🔒 Will this mod work for me?

This fork requests OpenGL 4.6 (4.1 on macOS). In the tested 26.3 migration, if SDL could not create the requested context, ThreatenGL retried with Minecraft's vanilla OpenGL 3.3 request.

**On macOS**, this mod will force OpenGL 4.1 instead of 4.6 as Apple deprecated OpenGL in favour of Metal starting with macOS Mojave (10.14) and has not updated it since.

The OpenGL 4.6 specification was released on July 31st, 2017. **Generally, this mod should work if:**

- you have an Nvidia Graphics Card from 2012 and upwards (Nvidia Kepler and above are supported)
- you have an AMD Graphics Card from 2012 and upwards (AMD GCN and above are supported)
- you have any Graphics Card which currently actively receives driver updates
- you have any Graphics Card which used to receive driver updates up until or after the release date of the OpenGL 4.6 specification

## ℹ️ Other Information & For those interested in the source code

This mod uses [Semantic Versioning 2.0.0](https://semver.org) to differentiate between different mod iterations.

Before modifying the source code and trying to compile, please edit the `gradle.properties` file and modify the following line:

This memory recommendation refers to the original root Gradle build. The Minecraft 26.3 Fabric profile has its own Gradle wrapper and requires Java 25.

**From:**

```properties
org.gradle.jvmargs=-Xmx8G
```

**To:**

```properties
org.gradle.jvmargs=-Xmx2G
```

This will reduce the amount of memory (RAM) given to Gradle, and is a highly recommended step for development if your device has less than 12GB of memory.

## Fork changes and Minecraft 26.3 status

This fork's sole intended target is Minecraft 26.3 with Fabric. Forge, NeoForge, Quilt, and other Minecraft versions are outside its support scope.

Minecraft 26.3 uses SDL for window and OpenGL-context setup. During development, an isolated Fabric migration was built and tested: it requested OpenGL 4.6 (4.1 on macOS) and fell back to Minecraft's vanilla OpenGL 3.3 request when SDL could not create the requested context.

The `fabric-26.3` source/build profile is included in this checkout. Build it on Windows with Java 25:

```powershell
.\fabric-26.3\gradlew.bat -p .\fabric-26.3 build
```

The JAR is written to `fabric-26.3\build\libs`. Build output is ignored by Git; upload the JAR as a GitHub Release asset rather than committing it to the source repository.

### Changes in this fork

- **Added:** The fork's release target is explicitly limited to Fabric on Minecraft 26.3; documentation of the SDL migration and this bilingual README.
- **Removed:** The shared initializer's GLFW-version diagnostic, which is not available in the Minecraft 26.3 SDL runtime.
- **Removed:** The temporary test-only option that forced an OpenGL 4.7 request. Normal behavior requests 4.6 (4.1 on macOS).
- **Not included:** The generated JAR; it is a Release asset and is not tracked in the source repository.
